How to automate weekly reports in Excel

The weekly report is the classic office chore: export, paste, fix the formulas, format, email. Most of it can be made to happen for you.

Checked 2026-11-18. Menus in other products change, so a label may differ slightly on your screen.

Short answer: stop rebuilding the report and start refreshing it. Keep one workbook where the raw data goes in one place and the report reads from it. Each week you replace the data and the report updates itself.

1. Separate the data from the report

This is the change that saves the most time, and it needs no special features.

  1. Put the raw export on its own sheet and format it as a table (select it, then Insert, Table).
  2. Build the report on a second sheet using formulas or a PivotTable that point at the table.
  3. Each week, paste the new export over the old rows. The table grows or shrinks and the report follows.
  4. If you use a PivotTable, choose Refresh All on the Data tab.

2. Let Excel fetch the data

Get Data on the Data tab, also called Power Query, can read a file or a folder and tidy it the same way every time: remove columns, fix dates, filter rows. You set the steps up once. After that, saving this week's export in the same place and choosing Refresh All does the rest. What Get Data can connect to depends on your version of Excel.

3. Record the formatting

If the last ten minutes are always the same clicks, such as column widths, bold headers and a print area, record them once as a macro and run it with one button. Macros run only in the desktop app, and your organisation may restrict them.

4. Run it on a schedule

Some Microsoft 365 business plans include Power Automate and Office Scripts, which can refresh a workbook stored in OneDrive or SharePoint and email it on a timetable. It is powerful, and it is closer to programming than the first three. It suits someone comfortable building flows.

What none of these do

  • Get the export for you. Someone still has to run the report in the accounts system or download the file.
  • Write the commentary. "Sales are down because two jobs slipped" is still typed by a person.
  • Notice that something looks wrong. A refresh will happily report a figure that is ten times too big.

How to choose

  • One report, one export: method 1 is enough.
  • Messy exports that need the same clean-up each week: add method 2.
  • You enjoy building things: method 4.
  • You want the report written and sent, with the "why" included: a tool like Steadywork.
