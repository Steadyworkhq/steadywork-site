# Demo video script (about 60–75 seconds, screen recording)

Record with the local demo and synthetic data. Every name on screen is fictional; say so in the caption. Phone-width screen recording works for Reels/TikTok/Pinterest; desktop for the landing page.

| Time | On screen | Voice-over / caption |
|---|---|---|
| 0–5s | A messy spreadsheet: names, table numbers, a blank cell, an accented name | "You've finally finished the seating plan. Now it has to become a chart, place cards… and something guests can actually find." |
| 5–12s | Drag the CSV onto the upload page | "Upload your spreadsheet, or just paste it." |
| 12–18s | Column-confirmation screen, "How we'll read it" table | "It finds your name and table columns. You confirm." |
| 18–26s | Review: "3 guests without a table", assign them; "Possible duplicates" → "These are different people" | "Missing a table? It tells you. Two guests named Jamie Lee? You decide. Nothing gets guessed or merged." |
| 26–34s | Choose Botanical, type names and date, pick 18×24 | "Pick a design and your exact print size." |
| 34–44s | Preview: zoom into the chart, scroll place cards, QR sign | "Check a preview with your real names before you pay." |
| 44–52s | Checkout → dashboard → download zip | "$99, one time. Your print files download instantly." |
| 52–62s | Phone: scan the QR sign, type a name, "Table 7" appears | "On the day, guests scan the sign, type their name, and see their table. No public list." |
| 62–70s | Edit a name on the dashboard; preview updates | "Last-minute change? Fix it and download fresh files. The QR page updates right away." |
| 70–75s | Landing page URL | "Seating chart, place cards and QR seat finder — [domain]." Caption: "Demo uses fictional names." |

Notes:
- Never show a real customer's data in marketing.
- No testimonials until real customers give permission in writing.
